# FanZone Live 🏆⚽

Aplicación móvil Android para reuniones deportivas. Encuentra personas con quien ver partidos en vivo.

## Tech Stack
- Kotlin + Android Studio
- Firebase Auth + Firestore + Storage
- Material Design (tema oscuro)
- Arquitectura MVVM

## Pantallas
- Login / Registro
- Home con filtros por deporte
- Detalle de evento + Solicitar unirse
- Crear evento
- Perfil de usuario
- Panel de Anfitrión
- Mundial 2026 integrado

## Deportes
⚽ Fútbol · 🏀 Basket · 🏎️ F1 · 🥊 Box · 🏆 Mundial 2026
